# 01. Python & NumPy Foundations

Welcome to **Python & NumPy Foundations**, the first chapter of my journey toward learning Deep Learning with PyTorch.

This chapter focuses on building a strong foundation in Python programming, NumPy, array manipulation, mathematical operations, and linear algebra. These concepts are essential for understanding how tensors, neural networks, and deep learning algorithms work internally.

## 🎯 Learning Objectives

- Understand Python fundamentals required for Deep Learning.
- Learn how to create and manipulate NumPy arrays.
- Perform mathematical and array operations using NumPy.
- Understand NumPy Broadcasting and its applications.
- Perform matrix multiplication and other matrix operations.
- Build a foundation in Linear Algebra for Machine Learning and Deep Learning.
